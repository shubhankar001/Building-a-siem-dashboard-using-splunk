# SIEM Dashboard

## Overview

The SIEM dashboard was created in Splunk Enterprise to provide centralized visibility into security events generated by the Ubuntu lab environment.

The dashboard combines authentication, web-server, firewall, and time-based security information.

## Dashboard Panels

### 1. SSH Failed Login Attempts

Displays failed SSH authentication attempts and helps identify repeated login attempts.

### 2. Apache HTTP Status Codes

Displays HTTP response codes generated by the Apache web server, such as `200` and `404`.

### 3. SSH Authentication Activity Over Time

Shows SSH authentication activity across time intervals.

### 4. Top SSH Attacker IPs

Identifies source IP addresses associated with repeated failed SSH authentication attempts.

### 5. Apache Web Requests Over Time

Visualizes the number of HTTP requests received by Apache over time.

### 6. Apache Error Activity

Shows Apache server errors over time.

### 7. Firewall Blocked Traffic

Displays source IP addresses associated with `IPTABLES-DROP` firewall events.

### 8. Total Security Events

Displays the total number of events available in the `ubuntulinux` index.

## Data Flow

```text
Ubuntu Log Sources
        ↓
Splunk Universal Forwarder
        ↓
Splunk Enterprise
        ↓
SPL Queries
        ↓
Dashboard Visualizations
```
## Purpose

The dashboard provides a centralized interface for monitoring and analyzing security activity within the lab environment.
