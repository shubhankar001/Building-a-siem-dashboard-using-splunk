# Splunk SPL Queries

This file contains the SPL queries used for security analysis in the SIEM dashboard.

## 1. SSH Failed Login Attempts

```spl
index=ubuntulinux sourcetype=linux_secure "Failed password"
| rex "from\s+(?<src_ip>\d{1,3}(?:\.\d{1,3}){3})"
| stats count by src_ip
| where count >= 3
| sort - count

```
Purpose

Identifies source IP addresses generating repeated failed SSH authentication attempts.

## 2. Apache HTTP Status Codes
```
index=ubuntulinux sourcetype=apache:access
| rex "\"\s(?<http_status>\d{3})\s"
| stats count by http_status
```
Purpose

Analyzes HTTP response status codes generated by the Apache web server.

## 3. SSH Activity Over Time
```
index=ubuntulinux sourcetype=linux_secure ("Failed password" OR "Invalid user")
| timechart span=5m count
```
Purpose

Visualizes SSH authentication activity over time.

## 4. Top SSH Attacker IPs
```index=ubuntulinux sourcetype=linux_secure ("Failed password" OR "Invalid user")
| rex "from\s+(?<src_ip>\d{1,3}(?:\.\d{1,3}){3})"
| stats count as attempts by src_ip
| sort - attempts
```
Purpose

Identifies source IP addresses associated with the highest number of failed SSH attempts.

## 5. Apache Requests Over Time
```index=ubuntulinux sourcetype=apache:access
| timechart span=5m count
```
Purpose

Shows the volume of Apache HTTP requests over time.

## 6. Apache Error Activity
```index=ubuntulinux sourcetype=apache:error
| timechart span=5m count
```
Purpose

Visualizes Apache server errors over time.

## 7. Firewall Blocked Traffic
```index=ubuntulinux sourcetype=linux_kernel "IPTABLES-DROP"
| rex "SRC=(?<src_ip>\d{1,3}(?:\.\d{1,3}){3})"
| stats count as blocked_packets by src_ip
| sort - blocked_packets
```
Purpose

Identifies source IP addresses generating firewall DROP events.

## 8. Total Security Events
```
index=ubuntulinux
| stats count as total_events
```
Purpose

Displays the total number of events available in the Ubuntu Splunk index.
